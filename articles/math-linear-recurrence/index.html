POINT 01

漸化式とは：前の項から次の項を決める式

漸化式は、前の項と次の項の関係を表します。例：an+1 = 2an + 3, a1 = 1 では、a2=5、a3=13、a4=29 と求まります。

しかし入試では「第100項」や「一般項 an」を求めることが多い。逐次計算よりも n の式に変形する方法が必要です。

違いを見よう

漸化式：an+1 = 2an + 3
一般項：an = 4·2n−1 − 3
一般項なら n=100 を直接代入できます。

最初の項 a1 がないと、多くの場合一般項が一意に定まりません。問題文では漸化式と初期条件をセットで読みます。

POINT 02

定数を引くと等比数列になる理由

an+1 = pan + q（p≠1）を考えます。「毎回同じ値 α が続く」場合の値を求めると、α = pα + q より α = q/(1−p) です。この α を固定点といいます。

an+1 − α = p(an − α)

上の式が成立するのは、α=pα+q だから。ここで bn = an−α と置くと bn+1=p bn。つまり bn は公比 p の等比数列になりました。

特性方程式の意味：高校数学でいう「特性方程式」α=pα+q は、数列の項をすべて同じ値に仮置きして、差を等比に変えるためのものです。
POINT 03

一般項の公式を自分で導く

b1=a1−α なので、等比数列の公式より bn=(a1−α)pn−1。元に戻せば、次の一般項が得られます。

an = α + (a1 − α)pn−1
ただし α = q/(1−p), p≠1
手順やること
①α=pα+q を解く
②bn=an−α と置く
③bn の等比数列の一般項を求める
④an に戻し、a1 と a2 を検算

公式は便利ですが、入試答案では変形過程が書けることを目標にしましょう。特に「αの符号」と指数 n−1 の書き違いが多いポイントです。

POINT 04

例題：aₙ₊₁＝2aₙ＋3、a₁＝1

最初に固定点を探します。α = 2α + 3 より α = −3。したがって an+1+3 = 2(an+3)。

bn = an+3 と置けば b1 = 1+3=4、公比 2。よって bn = 4·2n−1 なので、

an = 4·2n−1 − 3
最初の3項を確認

n=1：4−3=1
n=2：8−3=5
n=3：16−3=13
漸化式で計算した 1,5,13 と一致します。

よくある誤答は「+3を右辺から移項したつもりで an−3 と置く」こと。固定点 α=−3 を引くので an−(−3)=an+3 になります。

POINT 05

例外 p=1 と、解法を選ぶ基準

p=1 のとき固定点の式 α=q/(1−p) は分母が0になり使えません。このとき漸化式は an+1=an+q であり、公差qの等差数列そのものです。

p=1 のとき an = a1 + (n−1)q

例えば a1=3、an+1=an+5 なら an=5n−2。

見分けのコツ：「次の項＝p×前の項＋q」ならまず p=1 かを調べる。p≠1 なら固定点を引く、p=1 なら等差数列。この流れは定数係数の一次漸化式に使える。nによってpやqが変わる式には、そのまま適用できない。

Q01

a₁=2、aₙ₊₁=aₙ+4。一般項を求めよ。

解答と解説を見る ＋
正解・解答例

aₙ = 4n − 2

p=1 なので等差数列。aₙ=2+4(n−1)=4n−2。n=1で2になる。

Q02

a₁=1、aₙ₊₁=2aₙ+1。一般項を求めよ。

解答と解説を見る ＋
正解・解答例

aₙ = 2ⁿ − 1

α=2α+1 より α=−1。aₙ+1 は初項2、公比2の等比数列。aₙ+1=2·2ⁿ⁻¹=2ⁿ。

Q03

a₁=4、aₙ₊₁=3aₙ−6。一般項を求めよ。

解答と解説を見る ＋
正解・解答例

aₙ = 3 + 3ⁿ⁻¹

α=3α−6 より α=3。aₙ−3 は初項1、公比3。ゆえに aₙ=3+3ⁿ⁻¹。n=2で6、漸化式と一致。

Q04

a₁=5、aₙ₊₁=(1/2)aₙ+2。一般項を求めよ。

解答と解説を見る ＋
正解・解答例

aₙ = 4 + (1/2)ⁿ⁻¹

α=(1/2)α+2 より α=4。aₙ−4 は初項1、公比1/2の等比数列。

Q05

a₁=1、aₙ₊₁=2aₙ+3 の第4項を、一般項と漸化式の両方で確かめよ。

解答と解説を見る ＋
正解・解答例

a₄ = 29

一般項 aₙ=4·2ⁿ⁻¹−3 から a₄=32−3=29。一方、漸化式で a₂=5、a₃=13、a₄=29。両方一致する。

今日のまとめ

p≠1 なら α=pα+q の固定点を引き、差を等比数列に変える。p=1 なら等差数列。初期条件と最初の数項で必ず検算する。
