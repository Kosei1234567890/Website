形式主語it・形式目的語itの違い｜真主語とSVOCを見抜く

itは何を指す？「仮の席」と本当の内容を見分けよう。

約18分基礎〜応用例題3題・演習5問
目次学習目標導入：長い主語は後ろへ基本構造と見分け方図で比較：どこにitが座る？典型例題3題：根拠から解く応用：for・of・that節入試で失点しやすい4点段階別オリジナル演習5問と完全解説まとめと関連単元参考文献

学習目標

①形式主語と形式目的語の位置を区別する。②後ろに置かれたto不定詞・that節を意味の中心として読む。③SVOCと強調構文・天候のitを混同せず、英作文に使う。

導入：長い主語は後ろへ

To explain the rule in one sentence is difficult. は文法的には成立するが、長い主語を先頭に置くと読み始めに負担がかかる。そこで It is difficult to explain the rule in one sentence. として、主語の席に仮のitを置き、内容を後ろに送る。意味は「その規則を一文で説明するのは難しい」。

一方 We found it difficult to explain the rule. のitは動詞foundの後にある。こちらは形式目的語だ。日本語訳が似ていても、英文の構造は異なる。

基本構造と見分け方

種類語順例
形式主語It + be + 形容詞 + to do / that節It is useful to keep a diary.
形式目的語S + V + it + 形容詞 + to do / that節I find it useful to keep a diary.
通常の代名詞it が特定の物事を指すI bought a diary. I use it.

形式主語では it が主語S、形式目的語では it が目的語Oの位置を占める。後ろのto doやthat節は意味内容を担う。形式目的語では find / consider / make などの動詞と、形容詞・名詞の補語Cが組み合わさることが多い。

注意：「itの後ろにtoがあれば必ず形式主語」は誤り。itの位置と後続する構造を見よう。

図で比較：どこにitが座る？

同じ「毎日勉強するのは役立つ」でも、上は事実を述べ、下は「私は役立つと思う」という判断主体が加わる。

典型例題3題：根拠から解く

例題1｜形式主語に書き換え

To check the source carefully is essential. をitで始めよ。

解答：It is essential to check the source carefully.

解説：元の主語はTo check the source carefully全体。is essentialを維持し、仮の主語Itを先頭に置いて、to以下を後ろへ移す。

例題2｜SVOCを復元

We found ( difficult / it / to / the instructions / follow ). 語順を整えよ。

解答：We found it difficult to follow the instructions.

解説：foundの後に目的語it、補語difficult、内容を表すto follow...の順。We found difficult it...とはしない。

例題3｜itの種類

次のitを区別せよ。(A) It is snowing. (B) It is surprising that the answer is so simple. (C) It was Ken who solved the puzzle.

解答：Aは天候の非人称it、Bは形式主語、Cは強調構文。

解説：Bのthat節は「答えがこれほど単純なこと」という評価対象。CはKenを強調するIt was ... who ... の形で、通常の形式主語構文と役割が異なる。

応用：for・of・that節

It is important for beginners to ask questions. ではfor beginnersがto askの意味上の主語（質問する人）を表す。It was kind of her to help us. のof herは親切という人物評価に結びつく。forとofは機械的に交換できない。

It is clear that the two results differ. ではthat節が判断内容。I made it clear that I disagreed. ではmade（V）+ it（O）+ clear（C）+ that節（内容）。後者は「反対であることを明確にした」という意味になる。

なお It is three o'clock のitは時刻を表す非人称用法。後ろに真主語が隠れているとは考えない。

入試で失点しやすい4点

  • 形式目的語のitを省く：I find difficult to speak... は標準的なSVOC構文では不適切。I find it difficult to speak... とする。
  • itとthatを同一視：It is true that... のthat節は内容を表す。It is true it... とはしない。
  • for/ofを暗記だけで選ぶ：動作の主体ならfor、人物の性質への評価ならofが典型。
  • 強調構文を形式主語と混同：It was Maya that wrote the report. は「書いたのはマヤだ」と焦点を当てる。

段階別オリジナル演習5問と完全解説

基礎1｜空所

(　) is difficult to translate this poem literally.

解答・解説を開く

It。 to translate...が意味上の主語。文頭の主語位置を仮のItで埋める。

基礎2｜和訳と分類

I think it necessary to compare both reports.

解答・解説を開く

「両方の報告書を比較することが必要だと思う」。形式目的語。 think（V）+ it（O）+ necessary（C）+ to compare...（内容）の順。

標準3｜並べ替え

（ it / for / is / to / useful / students / review ）their mistakes.

解答・解説を開く

It is useful for students to review their mistakes. 形式主語It + be + useful + for students（復習する主体）+ to review...。

標準4｜誤文訂正

We made clear it that the schedule had changed.

解答・解説を開く

We made it clear that the schedule had changed. make + it（O）+ clear（C）+ that節（内容）。itとclearの順序を入れ替える。

応用5｜英作文

「私は、証拠なしに結論を出すのは危険だと思う」を形式目的語itとfindを使って英訳せよ。

解答・解説を開く

I find it dangerous to draw conclusions without evidence. find（判断）+ it（仮の目的語）+ dangerous（補語）+ to draw...（判断対象）。without evidenceは「証拠なしに」。主語をIとすることで「私はそう思う」を表す。

まとめと関連単元

判定の順序は①itの位置 ②動詞と補語 ③後ろのto不定詞・節 ④意味上の主体。主語位置なら形式主語、動詞の後で補語を伴うなら形式目的語を疑う。例外的な非人称itや強調構文は別に判定する。
