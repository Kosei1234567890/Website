ヘロンの公式を証明｜3辺だけで三角形の面積を求める方法

高さが分からなくても、3辺だけで面積を計算できる。

到達目標：ヘロンの公式を導き、計算と検算に使える。

POINT 01

学習目標と導入

三角形の3辺が分かっているのに、高さも角度も分からない。そんなときはヘロンの公式が有効です。①成立条件を確認する、②公式を導く、③根号の計算を整理する、④他の面積公式と使い分ける、の4点を目標にします。

三角形の辺を a,b,c、半周長を s=(a+b+c)/2 と置きます。面積 S は次の式で求められます。

S = √{s(s−a)(s−b)(s−c)}

長さの単位がcmなら、面積はcm²です。必ず a+b>c、b+c>a、c+a>b を確認します。

POINT 02

公式の導出：余弦定理から

辺 a と b の間の角を C、向かいの辺を c とすると S=(1/2)ab sin C です。余弦定理より cos C=(a²+b²−c²)/(2ab)。

sin²C=1−cos²C を使って両辺を二乗すると、16S²=4a²b²−(a²+b²−c²)²。

右辺は平方差として [2ab−(a²+b²−c²)][2ab+(a²+b²−c²)] に分解できます。さらに (c²−(a−b)²)((a+b)²−c²)=(a+b+c)(a+b−c)(a−b+c)(−a+b+c)。

s=(a+b+c)/2 と置けば4因子は順に 2s、2(s−c)、2(s−b)、2(s−a)。したがって16S²=16s(s−a)(s−b)(s−c)。面積Sは正なので平方根を取って公式が得られます。

POINT 03

典型例題① 3・4・5

問題：3辺が3cm、4cm、5cmの三角形の面積を求めよ。

解答：s=(3+4+5)/2=6。S=√{6(6−3)(6−4)(6−5)}=√(6×3×2×1)=√36=6cm²。直角三角形なので3×4÷2=6とも一致します。

POINT 04

典型例題② 二等辺三角形

問題：3辺が5cm、5cm、6cmの三角形の面積を求めよ。

解答：s=8、S=√{8×3×3×2}=√144=12cm²。底辺6の中点で分けると高さは√(5²−3²)=4、面積は6×4/2=12。別法で検算できます。

POINT 05

典型例題③ 根号を含む結果

問題：3辺が4cm、5cm、7cmの三角形の面積を求めよ。

解答：s=8、S=√{8×4×3×1}=√96=4√6cm²。√96=√(16×6)=4√6 と整理します。小数近似で終わらせず正確な値を示します。

POINT 06

ミスしやすい点と使い分け

半周長と周長を混同しない：sは3辺の和の半分です。存在しない三角形を計算しない：2、3、6は2+3<6で三角形になりません。直角三角形では底辺×高さが速い：与えられた情報に応じて公式を選びます。2辺とその間の角なら(1/2)ab sin C、3辺だけならヘロンの公式が候補です。

POINT 07

段階別演習5問・完全解説

  1. 基本：辺5、12、13の面積。
    解答と解説s=15。√(15×10×3×2)=√900=30。直角三角形の面積5×12/2でも30。
  2. 基本：辺6、8、10の面積。
    解答と解説s=12。√(12×6×4×2)=√576=24。
  3. 標準：辺7、8、9の面積。
    解答と解説s=12。√(12×5×4×3)=√720=12√5。
  4. 標準：辺10、10、12の面積。
    解答と解説s=16。√(16×6×6×4)=√2304=48。底辺12、高さ8でも確認できます。
  5. 応用：辺x、x、12の三角形の面積が48。xを求めよ。
    解答と解説底辺12の二等辺三角形なので高さh=2×48/12=8。底辺の半分は6、三平方よりx²=6²+8²=100。辺長は正だからx=10。ヘロンでs=x+6としてS²=(x+6)(6)(6)(x−6)=36(x²−36)=2304からもx=10。

問題の辺長の単位をcmとすると、面積の単位はcm²です。

POINT 08

まとめと関連単元

3辺を知っているとき、半周長sを作り、s、s−a、s−b、s−cを掛けて平方根を取ります。三角不等式を先に確認し、最後は根号を簡単にします。
