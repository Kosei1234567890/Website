完了「ぬ」と打消「ず」の連体形「ぬ」を区別できる／前の動詞の活用形を特定できる／係り結びと文末の形から訳を確かめられる。

POINT 01

「ぬ」には正反対の2つの意味がある

古文で見かける「ぬ」は、完了の助動詞「ぬ」と、打消の助動詞「ず」の連体形「ぬ」の2種類が基本です。前者は「〜た／〜てしまった」、後者は「〜ない」という反対の意味になります。

種類前の動詞意味原則としての形
完了「ぬ」連用形に接続〜た、〜てしまった終止形が「ぬ」
打消「ず」未然形に接続〜ない連体形が「ぬ」
まずは四段動詞で比べる

花も散りぬ。 ＝花も散ってしまった。（「散り」は連用形）
花の散らぬ庭 ＝花が散らない庭。（「散ら」は未然形）

「ぬ」自体だけを見ても、どちらかは判定できません。前の語・後ろの語・文全体を確認することが出発点です。

POINT 02

最優先は直前の動詞の活用形

打消「ず」は未然形に接続し、完了「ぬ」は連用形に接続します。四段活用のように未然形と連用形が区別しやすい場合は、直前の一文字だけで判定できることがあります。

動詞未然形＋ぬ（打消）連用形＋ぬ（完了）
書く（カ行四段）書かぬ＝書かない書きぬ＝書いてしまった
咲く（カ行四段）咲かぬ＝咲かない咲きぬ＝咲いてしまった
待つ（タ行四段）待たぬ＝待たない待ちぬ＝待ち終えた

「なぜ『ぬ』の前の活用を確認するのか」を説明できるようにしておこう。接続とは助動詞がどの活用形の後につくかというルールだからです。

試験の落とし穴：「ぬ」を見たらすぐ現代語訳を書かず、動詞の原形を考える。たとえば「行かぬ」は「行く」の未然形「行か」＋打消、「行きぬ」は連用形「行き」＋完了。
POINT 03

下二段など、見た目が同じなら後ろを読む

下二段活用の「見ゆ」では、未然形と連用形がどちらも見えです。したがって「見えぬ」は接続だけでは見分けられません。そこで「ぬ」自体の活用形を確認します。

助動詞未然連用終止連体已然命令
完了「ぬ」なにぬぬるぬれね
打消「ず」（本活用）ずずずぬね—

見えぬ山 は「山」という名詞を直接修飾するので、「ぬ」は連体形。打消の「ぬ」と判断できます。完了「ぬ」の連体形は「ぬる」だからです。

一方、月が見えぬ。 のように文末に終止形として置かれた「ぬ」は、通常は完了の「ぬ」と考えられます。ただし、古文には連体形で文を終える表現もあるため、文脈と係り結びも確認するのが安全です。

POINT 04

「ぞ・なむ・や・か」と係り結びが決め手になる

係助詞ぞ・なむ・や・かがあると、原則として文末は連体形で結びます。「こそ」なら已然形で結びます。このルールは助動詞の識別に直結します。

自作の例文

星ぞ見えぬ。：「ぞ」があるので結びは連体形。完了「ぬ」の連体形は「ぬる」なので、この「ぬ」は打消。「星が見えない」と読む。
鐘も鳴りぬ。：「鳴り」は四段動詞の連用形。完了「ぬ」で「鐘も鳴った」。

ただし、係り結びの省略・流れなど、典型例から外れる文もあります。入試の識別問題では、まず接続と活用形という機械的に確かめられる根拠を使い、前後の内容で不自然でないか検証します。

解き方：①ぬの直前を活用させる → ②ぬの後ろに名詞があるか → ③ぞ・なむ・や・か・こそを探す → ④訳の意味が通るか。
POINT 05

入試の記述答案は「根拠→識別→訳」の順に

例えば「旅人は門を出でぬ。」と「門を出でぬ人」は、直前の「出で」がどちらも下二段活用動詞「出づ」の未然形・連用形と同形です。

文根拠解釈
旅人は門を出でぬ。通常の文末の終止形「ぬ」旅人は門を出てしまった（完了）
門を出でぬ人名詞「人」を修飾する連体形「ぬ」門を出ない人（打消）

記述なら「『出づ』は下二段活用で『出で』は未然・連用同形だが、ここでは名詞『人』を修飾する連体形『ぬ』なので、打消『ず』の連体形」と説明できます。

よくある誤りは「完了だから過去形」と言い切ること。完了は動作が完了したことを示し、単純な過去の「き・けり」と同じではありません。文脈に合わせて「〜てしまった」「〜た」などと訳しましょう。

Q01

「花も散りぬ。」の「ぬ」は完了と打消のどちらか。接続を根拠に答えよ。

解答と解説を見る ＋
正解・解答例

完了の助動詞「ぬ」。

四段動詞「散る」の連用形は「散り」。完了「ぬ」は連用形に接続する。「花も散ってしまった」。

Q02

「風の吹かぬ夜」の「ぬ」を識別し、訳せ。

解答と解説を見る ＋
正解・解答例

打消の「ず」の連体形。「風が吹かない夜」。

「吹く」の未然形は「吹か」。打消「ず」は未然形に接続し、後ろの名詞「夜」を修飾する。

Q03

「見えぬ山」の「ぬ」を、直前の活用形だけで確定できない理由を答えよ。

解答と解説を見る ＋
正解・解答例

「見ゆ」は下二段活用で、未然形・連用形がともに「見え」だから。

接続だけでは両方可能。しかし名詞「山」を修飾するため「ぬ」は連体形。打消が妥当。

Q04

「星ぞ見えぬ。」の「ぬ」はどちらか。係り結びを使って説明せよ。

解答と解説を見る ＋
正解・解答例

打消「ず」の連体形。

係助詞「ぞ」の結びは連体形。完了「ぬ」の連体形は「ぬる」、打消「ず」の連体形は「ぬ」。

Q05

「旅人は門を出でぬ。」と「門を出でぬ人」の「ぬ」をそれぞれ識別せよ。

解答と解説を見る ＋
正解・解答例

前者は通常、完了の終止形。後者は打消の連体形。

「出づ」の「出で」は未然・連用同形。文末では完了「ぬ」の終止形が基本。一方、名詞「人」を直接修飾するのは打消「ず」の連体形「ぬ」。
