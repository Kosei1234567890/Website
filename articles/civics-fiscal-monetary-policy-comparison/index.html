財政政策と金融政策の違い｜景気対策・乗数の計算まで

政府と中央銀行の役割を混同しない。政策の仕組みを例題で理解する。

基礎〜応用例題3題・演習5問
目次学習目標導入：景気を動かす二つのハンドル政策の主体と手段を比較なぜ総需要が動くのか入試計算：単純な支出乗数典型例題3題失点しやすいポイント段階別演習5問と完全解説まとめ・関連学習

学習目標

財政政策と金融政策の実施主体・手段・波及経路を区別し、景気後退と物価上昇への政策を理由つきで選べる。単純な乗数モデルの計算もできるようにする。

導入：景気を動かす二つのハンドル

不況で店の売上が落ちたとき、政府が道路を発注すれば直接仕事が増える。一方、中央銀行が金利を下げると、企業が設備投資のために借り入れやすくなる場合がある。前者が財政政策、後者が金融政策。どちらも総需要に働きかけるが、入口が違う。

政策の主体と手段を比較

政策の比較（典型的な短期の方向）
観点財政政策金融政策
主体政府・国会の予算や税制中央銀行（日本では日本銀行）
主な手段政府支出・税・給付政策金利・資金供給・国債買入れ等
景気を支える方向支出増・減税金利低下など金融緩和
過熱を抑える方向支出抑制・増税金利上昇など金融引締め

これは一般的な方向であり、効果の大きさは物価、期待、金利、供給能力などに左右される。国債買入れを単純に「政府が支出する」と混同しないこと。

なぜ総需要が動くのか

短期の総需要は、消費 C・投資 I・政府支出 G・純輸出 NX の合計として AD = C + I + G + NX と整理できる。政府支出 G の増加は直接ADを押し上げる。一方、金融緩和は金利などを通じて投資 I や消費 C を変化させる間接的な経路が中心である。

この図は方向を示す模式図で、必ず同じ結果になるという意味ではない。金利が下がっても企業が投資を控える場合などは効果が弱まる。

入試計算：単純な支出乗数

輸入・税・物価変化を考えない単純なケインズ型モデルで、限界消費性向を c（0<c<1）とすると、追加所得のうち c が消費される。政府支出が ΔG 増えると、需要増は ΔG + cΔG + c²ΔG + … となり、等比級数の和から ΔY = ΔG/(1−c) を得る。現実の効果をそのまま予測する式ではない。

典型例題3題

例題1：主体を判定

政府が所得税を減税した。金融政策か財政政策か。

財政政策。税率を変えるのは政府・立法の政策であり、中央銀行の金利操作ではない。

例題2：不況と金融政策

需要不足の不況で政策金利を引き下げる狙いを説明せよ。

借入金利の低下などを通じ、企業の設備投資や家計の支出を後押しし、総需要を増やす狙いがある。ただし効果は確実ではない。

例題3：乗数計算

限界消費性向0.8、政府支出増20億円。単純モデルで所得の増加額は。

乗数は 1/(1−0.8)=5。したがって ΔY=20×5=100億円。20億円を単純に5倍する根拠は、追加所得が再び消費に回る連鎖である。

失点しやすいポイント

  • 「政府が国債を発行」＝金融政策、ではない。政府の資金調達と中央銀行の金融調節は区別する。
  • 「金利を下げれば必ず景気回復」は誤り。期待や信用制約、供給面の事情で効き方は異なる。
  • 需要が増える政策は、供給能力が限られると物価上昇圧力も強めうる。
  • 乗数 1/(1−c) は仮定つき。税・輸入・物価などを含む現実の推計値ではない。

段階別演習5問と完全解説

基礎1

公共事業費を増やす政策の主体と種類を答えよ。

解答・解説

政府による拡張的財政政策。政府支出 G の増加が総需要に直接作用する。

基礎2

中央銀行が政策金利を引き上げるのは通常、金融緩和か引締めか。

解答・解説

金融引締め。借入れを抑制する方向に働き、需要・物価上昇圧力を弱めることを狙う。

標準3

限界消費性向0.75、政府支出増12億円。単純モデルの所得増は。

解答・解説

1/(1−0.75)=4。12×4=48億円。所得増の連鎖を等比級数で表した結果。

標準4

減税しても家計が将来不安から貯蓄を増やした。想定より景気刺激が弱い理由は。

解答・解説

可処分所得が増えても消費に回る割合が小さいため。減税額の全額が即座に総需要増となるわけではない。

応用5

政府が景気刺激のため支出を増やし、中央銀行がインフレ抑制のため金利を上げた。政策の組合せと起こりうる結果を説明せよ。

解答・解説

拡張的財政政策と引締め的金融政策の組合せ。政府支出増は需要を押し上げる一方、金利上昇は民間投資・消費を抑えうる。したがって総需要への純効果は一方向に断定できず、政策の強さや経済状況による。

まとめ・関連学習

財政＝政府の支出と税、金融＝中央銀行の金利と資金供給。「誰が・何を・どの経路で変えるか」を順番に答えれば、政策の組合せ問題にも対応できる。
