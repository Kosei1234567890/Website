仮定法未来のshould・were to｜可能性と倒置を例文で区別

「万一」と「仮に」は同じ？ 未来の条件を意味・形・倒置から整理。

核心：未来の条件は「起きるかどうか」についての話し手の見方で表現が変わります。

学習目標と導入

「もし明日、突然学校が休みになったら？」という条件を英語にする際、話し手がその出来事をどの程度現実的と考えるかによって形が変わります。本記事の目標は、①普通の未来条件、②if＋should、③if＋were toを意味と形で区別し、④ifを省いた倒置まで正しく書けることです。

3つの未来条件を見分ける

普通の条件：If it rains tomorrow, we will stay home.（明日雨なら家にいる）。条件節は現在形で、未来の可能性を自然に述べます。

if＋should＋原形：If the train should stop unexpectedly, follow the staff's instructions.（万一列車が予期せず止まったら、係員の指示に従ってください）。「万一〜なら」の偶発的な条件を示し、主節は命令文・will・canなどさまざまです。shouldがあるからといって主節を必ずwouldにするわけではありません。

if＋were to＋原形：If the city were to lose electricity for a week, many services would stop.（仮に街が1週間停電するとしたら、多くのサービスが止まるだろう）。実現しそうにない、あるいは想像上の未来を改まって提示します。典型的には主節にwould/could/might＋原形を置きます。

未来条件の比較（典型形）
形話し手の捉え方主節の例
if＋現在形実際にあり得るwill go
if＋should＋原形万一・偶然に起きたらcall / will call
if＋were to＋原形仮想的・実現可能性が低いwould go

これは意味の傾向であり、出来事の確率を数字で断定する文法ではありません。文脈が最優先です。

図で整理：条件節と主節

ifを省く倒置

改まった文体では、ifを省いてShould＋主語＋動詞原形、またはWere＋主語＋to＋動詞原形の語順にできます。

If you should need help, contact us. → Should you need help, contact us.

If the plan were to fail, we would reconsider it. → Were the plan to fail, we would reconsider it.

倒置の際はifを残さないこと。Were to the plan fail ... のように主語を飛ばすのも誤りです。

典型例題3題

例題1（基礎）

「万一鍵をなくしたら、すぐ私に電話してください」をshouldを使って英訳せよ。

解答：If you should lose your key, call me immediately. 条件節はshould＋lose、主節は命令文call。wouldを無理に補う必要はありません。

例題2（標準）

「仮に太陽が突然消えるとしたら、地球上の生命は大きな影響を受けるだろう」をwere toで英訳せよ。

解答：If the sun were to disappear suddenly, life on Earth would be severely affected. were to disappearで仮想の未来、would be affectedで受動態の結果を示します。これは文法練習の仮想設定です。

例題3（応用）

If the manager should change the schedule, we will notify everyone. をifを用いず書き換えよ。

解答：Should the manager change the schedule, we will notify everyone. ifを消し、shouldを主語the managerの前へ。主節のwillは変えません。

頻出ミスと見分け方

  • shouldの後に過去形：× should changed → ○ should change。助動詞の後は原形。
  • were toの後に三単現：× were to changes → ○ were to change。to不定詞の動詞原形。
  • 主節を一律wouldにする：should節には命令文やwill節も自然です。
  • 過去形＝過去の話と思う：were toは未来の仮想を表すことがあります。
  • 倒置でifを残す：× If should you need ... → ○ Should you need ...。

段階別演習5問と完全解説

問1（基礎）

If she should (arrives / arrive) early, ask her to wait. 正しい形を選べ。

解答・解説を表示

arrive。shouldは助動詞なので後続の動詞は原形。訳は「万一彼女が早く着いたら、待つよう頼んで」。

問2（基礎）

「万一火災警報が鳴ったら、この出口を使ってください」をif＋shouldで英訳せよ。

解答・解説を表示

If the fire alarm should ring, use this exit. should ringが条件、useは命令形。ringの代わりにgo offも自然です。

問3（標準）

If we were to move abroad, we (will / would) need to learn another language. 選択せよ。

解答・解説を表示

would。仮想的な未来条件were to moveに対応する典型的な帰結はwould need。「もし海外に移住することになったとしたら、別の言語を学ぶ必要があるだろう」。

問4（標準）

If the company were to close, many workers would lose their jobs. を倒置にせよ。

解答・解説を表示

Were the company to close, many workers would lose their jobs. ifを削除しwereを主語the companyの前へ。to closeは主語の後に残します。

問5（入試応用）

Should any questions arise, please email the office. をifで始まる文に直し、日本語に訳せ。

解答・解説を表示

If any questions should arise, please email the office. 「万一何か質問が生じた場合は、事務局にメールしてください」。Should＋主語＋原形はif＋主語＋should＋原形の倒置。ariseは自動詞で「生じる」。

まとめ・関連記事・参考文献

まとめ：if＋現在形は普通の未来条件、if＋shouldは「万一」、if＋were toは想像上の未来。倒置はShould＋主語＋原形／Were＋主語＋to＋原形。主節は機械的に固定せず、意味と文脈で判断しましょう。
