相加平均・相乗平均の不等式｜等号成立と最小値の見抜き方

公式を丸暗記せず、なぜ成り立つか・いつ最小値になるかを見抜こう。

約20分基礎〜入試応用例題3題・演習5問
この記事の目次学習目標なぜ「均等に分ける」と積が大きいのか定理と証明典型例題3題ありがちな失点段階別オリジナル演習5問・完全解説まとめ・関連単元

学習目標

正の2数の相加平均・相乗平均の大小関係を平方の非負性から証明し、等号成立条件を確認してから最小値を決定できる。さらに、使えない場合を反例で判定する。

なぜ「均等に分ける」と積が大きいのか

長さの合計が10の2本の辺で長方形を作る。辺が1と9なら面積9、3と7なら21、5と5なら25。合計を固定すると、2つを等しくしたとき積が最大になる。この直感が相加平均・相乗平均の不等式（AM–GM）につながる。

定理と証明：出発点は「平方は0以上」

a ≥ 0、b ≥ 0 のとき、(a+b)/2 ≥ √(ab) が成り立つ。特に等号成立は a=b のとき、かつそのときに限る。

証明： (√a−√b)² ≥ 0 を展開すると a+b−2√(ab) ≥ 0。両辺を2で割れば (a+b)/2 ≥ √(ab)。等号成立は √a−√b=0、すなわち a=b の場合だけ。

よく使う形は a+b ≥ 2√(ab)。平方根の中にある積が定数なら、和の下限を即座に求められる。

典型例題3題：条件→不等式→等号

例題1：x+16/x の最小値（x>0）

x と16/x はともに正で、積は16。よって x+16/x ≥ 2√16=8。等号成立は x=16/x、すなわち x²=16。x>0 より x=4 が実際に許される。最小値8（x=4）。

例題2：x+y=12、x>0、y>0 のとき xy の最大値

12=x+y ≥ 2√(xy) より √(xy)≤6、両辺非負なので xy≤36。等号成立は x=y=6 で和の条件も満たす。最大値36。

例題3：x>0 のとき 2x+9/x の最小値

2x と9/x の積は18。よって 2x+9/x ≥ 2√18=6√2。等号は2x=9/x → 2x²=9 → x=3/√2。条件を満たすので最小値6√2。単に x と9/x を等しくするのではなく、実際に足している2x と9/xを等しくする。

ありがちな失点：等号が成立しない下界は最小値ではない

① 正負を無視しない。x<0 では x と1/x はともに負であり、正数用の不等式をそのまま当てはめられない。② 積が一定か確認する。x+(x+1) は積が変化し、AM–GMを適用しても定数の下限は直ちに出ない。③ 等号を達成する値が定義域にあるか必ず調べる。

反例：x≥3 のとき x+1/x ≥2 は正しいが、等号 x=1 は定義域外。実際、f(x)=x+1/x は x≥3 で増加する（x₂>x₁≥3 なら差は (x₂−x₁)(1−1/(x₁x₂))>0）。最小値は x=3 で 10/3。2ではない。

段階別オリジナル演習5問・完全解説

基礎1

正の数 a,b について (a+b)/2=7 のとき ab の最大値と等号条件を求めよ。

解答・解説を開く

√(ab)≤7 なので ab≤49。a=b=7 なら平均7を満たす。最大49。

基礎2

x>0 のとき x+25/x の最小値とそのときの x を求めよ。

解答・解説を開く

x·(25/x)=25。和は2√25=10以上。等号 x=25/x → x²=25、x>0より x=5。最小10。

標準3

t>0 のとき 3t+12/t の最小値を求めよ。

解答・解説を開く

3t·12/t=36、和は2√36=12以上。3t=12/t → t²=4 → t=2。最小12。

標準4

正の数 x,y が 2x+3y=18 を満たすとき xy の最大値を求めよ。

解答・解説を開く

18=2x+3y≥2√(6xy)。よって9≥√(6xy)、81≥6xy、xy≤27/2。等号2x=3y、かつ2x+3y=18より2x=3y=9、x=9/2、y=3。最大27/2。

応用5

x≥4 のとき x+4/x の最小値を求め、「AM–GMで4と答える」誤りを説明せよ。

解答・解説を開く

AM–GMでは x+4/x≥4、等号は x=2 だが定義域 x≥4 に含まれない。x₂>x₁≥4 に対し f(x₂)−f(x₁)=(x₂−x₁)(1−4/(x₁x₂))>0 なので単調増加。x=4 で最小4+1=5。下界4は達成不能。

まとめ・関連単元

AM–GMを使う前に非負・積が一定・等号成立の3点を確認する。和の最小値と積の最大値は対になる。関連：二次関数の最大・最小、対数方程式・不等式、数学の記事一覧。
