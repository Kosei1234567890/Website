as if・as thoughの仮定法｜時制のずれ・事実との距離・直説法を見分ける

「現在なのに過去形？」を時間関係と現実性から整理し、英作文まで解ける。

約18分基礎〜応用例題3題・演習5問
目次学習目標導入：現在の話なのに過去形？基本構造と時制の対応典型例題3題入試応用：訳すときは断定しすぎないミスしやすい点段階別オリジナル演習5問まとめ・関連単元

学習目標

① as if / as though が「まるで〜のように」と比較する構造を理解する。② 過去形・過去完了形が表す現実との距離を判断する。③ 実際に起こりそうな事柄を直説法で表す場合と区別し、入試の空所補充・和訳・英作文に応用する。

導入：現在の話なのに過去形？

He talks as if he knew everything. は「彼は何でも知っているかのように話す」。talks は現在なのに knew は過去形だ。ここでの過去形は、単に過去の出来事を示すのではない。「実際は何でも知っているわけではない」という現実との隔たりを表している。

対照的に It looks as if it is going to rain. は「雨が降りそうだ」。根拠に基づく現実的な推測なら、仮定法にせず直説法を使える。

基本構造と時制の対応

構造典型的な意味例
as if + 過去形主節と同時点の非現実的な様子She acts as if she owned the shop.
as if + had + 過去分詞主節の時点より前の非現実的な出来事He looked as if he had seen a ghost.
as if + 直説法現実的な可能性・観察It sounds as if someone is outside.

重要：「主節が現在なら過去形、主節が過去なら過去完了形」と機械的に決めない。比較の対象となる出来事が主節と同時か、それより前かを先に考える。たとえば He spoke as if he knew the answer. では過去の発言と同時に「知っているふり」をしているので knew が自然だ。

be動詞では、非現実的な仮定を明確にする場合 were が用いられる（He talks as if he were the boss.）。くだけた用法では was も見られる。as though も基本的に同じ意味・構文を取る。

時間関係を図で確認

この図は「仮定法として非現実を描く場合」の整理であり、直説法を使う現実的な推測まで一律に当てはめるものではない。

典型例題3題

例題1｜同時の非現実

He speaks as if he (know) every answer. 「彼はすべての答えを知っているかのように話す」。実際には知らない、という含みで括弧内を変形せよ。

解答：knew。 speaks と同時に「知っているかのように」振る舞うので、仮定法過去 knew を用いる。had known にすると発言より前に知っていた、という時間関係に寄る。

例題2｜先行する非現実

She looked as if she (see) something terrible before entering the room. 非現実的な比喩として括弧内を変形せよ。

解答：had seen。 見た（と想定する）時点は looked より前。したがって仮定法過去完了 had seen。before entering the room が先行関係の手掛かり。

例題3｜直説法を見抜く

Dark clouds are gathering. It looks as if it (rain) soon. 現実的な予測として自然な形を答えよ。

解答例：is going to rain。 黒い雲という観察根拠があり、実際に雨が降る可能性を述べている。as if の後は必ず仮定法になるわけではない。

入試応用：訳すときは断定しすぎない

She smiled as though nothing had happened. は「何事もなかったかのように彼女はほほ笑んだ」。nothing had happened は微笑んだ時点より前に関する表現だが、文だけから実際に何が起こったかを断定しない。「まるで〜」という話し手の描写に注目する。

He looked as if he were tired. は「疲れているように見えた」。外見からの推測を述べるときは He looked as if he was tired. も自然に用いられる。入試では「were は非現実を強調する形」「直説法も文脈次第で可能」という区別が大切だ。

ミスしやすい点

  • as if があれば必ず過去形にする、は誤り。直説法も使える。
  • 主節が過去形だから as if 節は必ず過去完了、は誤り。同時なら過去形の仮定法もあり得る。
  • 過去完了を「過去の事実」と断定しない。非現実を描く形と時間の前後関係を分ける。
  • as though を「〜だけれども」と訳さない。ここでは as if と同じ「まるで〜のように」。

段階別オリジナル演習5問

基礎1

He behaves as if he (be) our teacher.（実際には教師ではない。改まった仮定法）

解答・解説

were。 現在の振る舞いと同時の非現実。be の仮定法過去 were を用いる。

基礎2

She talked as though she (own) the entire building.（実際には所有していない）

解答・解説

owned。 過去の発言と同時点の非現実。talked につられて had owned にしない。

標準3

He stared at me as if he (meet) me before.（実際には会っていないという含み）

解答・解説

had met。 「以前会った」は stare した時点より前の出来事。非現実の過去完了を用いる。

標準4

There is a strange noise upstairs. It sounds as if someone (walk) around.（現実的な推測、現在進行中）

解答・解説

is walking。 音という根拠から「誰かが歩き回っているようだ」と推測。直説法現在進行形が自然。

応用5

「彼女は昨日、以前その本を読んだことがあるかのように話した。しかし実際には読んでいなかった」を as if を使って英訳せよ。

解答・解説

She spoke yesterday as if she had read the book before, but in fact she had not read it. 発言より前の読書経験を非現実として描くので had read。後半も「昨日までに読んでいなかった」ため過去完了を使って時間関係を明確にする。

まとめ・関連単元

as if / as though は「まるで〜のように」。非現実なら主節と同時は過去形、主節より前は過去完了形を目安にする。ただし現実的な推測には直説法も使える。時間関係と現実性を別々に判断するのが最重要。
