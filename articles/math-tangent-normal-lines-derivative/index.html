到達目標：微分係数の意味、接線・法線の方程式、接点が未知の場合の立式を理解する。

POINT 01

学習目標と直感

曲線の一点を拡大すると、その近くで直線のように見えます。その方向を表すのが接線。接線と直角に交わる直線が法線です。この記事では①微分係数と接線の傾きを結び付ける、②法線の式を求める、③接点が指定されない問題を解く、の3段階を目標にします。

POINT 02

定義から公式を導く

曲線 y=f(x) 上の P(a,f(a)) と Q(a+h,f(a+h)) を結ぶ割線の傾きは [f(a+h)−f(a)]/h。h→0 の極限が存在するとき、その値が f′(a) です。したがって接線は y−f(a)=f′(a)(x−a)。接線の傾きを m≠0 とすると、垂直な法線の傾きは −1/m なので y−f(a)=−(x−a)/f′(a)。ただし f′(a)=0 のとき接線は y=f(a)、法線は x=a です。

POINT 03

典型例題① 接点が指定される

問題：y=x²−2x+3 の x=2 における接線と法線を求めよ。

解説：f(2)=4−4+3=3 なので接点は (2,3)。f′(x)=2x−2 より f′(2)=2。接線は y−3=2(x−2)、すなわち y=2x−1。法線の傾きは −1/2 なので y−3=−(x−2)/2、すなわち y=−x/2+4。両直線の傾きの積は −1 です。

POINT 04

典型例題② 水平接線と垂直法線

問題：y=x²−4x+1 の接線が水平になる点と、その法線を求めよ。

解説：f′(x)=2x−4=0 から x=2。f(2)=4−8+1=−3。接点 (2,−3) で接線は y=−3、法線は x=2。傾き −1/0 を計算してはいけません。垂直線は y=mx+b の形にできません。

POINT 05

典型例題③ 曲線外の点から引く接線

問題：点 (0,−1) を通り、放物線 y=x² に接する直線をすべて求めよ。

解説：接点の x 座標を t とすると接点は (t,t²)、傾きは 2t。接線は y−t²=2t(x−t)、整理して y=2tx−t²。これが (0,−1) を通るので −1=−t²、つまり t=±1。したがって y=2x−1、y=−2x−1 の2本。接点を先に (0,−1) と決めるのは誤りです。

POINT 06

ミスしやすい4点

① 接線は「1点でしか交わらない」ではない：接線は曲線と別の点で再び交わることがあります。② 微分した値と座標を混同しない：f(a) は高さ、f′(a) は傾き。③ 法線の符号：m の逆数ではなく負の逆数。④ 傾き0：法線は x=a と書く。

段階別練習問題5問・完全解説

問1（基礎）

y=x²+1 の x=1 での接線を求めよ。

解答・途中式を表示

接点は (1,2)、f′(1)=2。y−2=2(x−1) より y=2x。

問2（基礎）

y=x³ の x=0 での接線と法線を求めよ。

解答・途中式を表示

f(0)=0、f′(x)=3x²、f′(0)=0。接線 y=0、法線 x=0。

問3（標準）

y=x²−6x+5 の x=2 での法線を求めよ。

解答・途中式を表示

接点は (2,−3)、f′(2)=−2。法線の傾きは 1/2。y+3=(x−2)/2、すなわち y=x/2−4。

問4（標準）

y=x² に傾き6の接線を引く。接点と接線を求めよ。

解答・途中式を表示

f′(t)=2t=6 から t=3。接点 (3,9)、y−9=6(x−3) より y=6x−9。

問5（応用）

点 (0,−4) を通る y=x² の接線をすべて求めよ。

解答・途中式を表示

接点を (t,t²) とすると接線 y=2tx−t²。点を代入して −4=−t²、t=±2。よって y=4x−4 と y=−4x−4。

まとめ・関連単元

接線は「接点の座標」と「微分係数」を使って点傾きの式に代入。法線は垂直条件を使い、傾き0の場合は縦線を別扱いします。接点が未知なら文字 t で置き、指定された通過点を最後に代入します。
