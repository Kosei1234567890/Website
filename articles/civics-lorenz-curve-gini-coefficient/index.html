ローレンツ曲線とジニ係数｜所得格差を図と面積で読み解く

「平均年収が同じなら格差も同じ？」をグラフと数値で検証する。

基礎〜応用例題3題演習5問

公

到達目標：①累積割合を読み取る ②ジニ係数を面積から導く ③格差と所得水準を混同しない。

POINT 01

目標と導入

3人の年収が「300・300・300万円」の社会と「0・0・900万円」の社会。どちらも平均は300万円ですが、分配はまったく違います。平均値だけでは見えない格差を調べる道具がローレンツ曲線とジニ係数です。

ここでは所得が0以上で、比較する単位を世帯に統一した架空データを使います。実際の統計では所得の種類、世帯構成、税・社会保障による再分配の前後を確認します。

POINT 02

ローレンツ曲線の読み方

世帯を所得の低い順に並べます。横軸は世帯の累積割合、縦軸はその世帯群が受け取る所得の累積割合です。例えば「下位50％の世帯が所得全体の20％を得る」なら、グラフ上の点は(0.5, 0.2)です。

全世帯の所得が同じなら、下位30％が所得の30％を受け取り、グラフは45度の均等分布線になります。格差があると、低所得層の累積所得割合が小さくなるため、曲線は均等分布線より下に位置します。

POINT 03

ジニ係数の面積と公式

均等分布線とローレンツ曲線の間の面積をA、ローレンツ曲線の下の面積をBとすると、ジニ係数 G=A/(A+B)。両軸を0〜1に取ると均等分布線の下の三角形は面積1/2なので、G=2A=1−2Bと変形できます。

完全平等ならA=0でG=0。極端に集中するほど1に近づきます。ただし有限個の世帯では、全所得を1世帯が独占しても通常のジニ係数は厳密には1になりません。大きいほど格差が大きいという方向を覚えましょう。

折れ線の点を(x₀,y₀), …, (xₙ,yₙ)とし、端点を(0,0)、(1,1)とすると、台形の面積を足してB=Σ[(xᵢ−xᵢ₋₁)(yᵢ+yᵢ₋₁)/2]。したがってG=1−Σ[(xᵢ−xᵢ₋₁)(yᵢ+yᵢ₋₁)]です。階級別の資料から計算するときは、階級内を直線で結ぶ近似になることに注意します。

POINT 04

典型例題3題

問：下位25％の世帯が所得の10％を受け取る。曲線上の点は？

解答・解説：(0.25,0.10)。先に横軸＝世帯割合と確認し、所得割合を縦に置きます。

問：曲線の下の面積Bが0.35のときジニ係数は？

解答・解説：G=1−2×0.35=0.30。均等分布線の下の面積が0.5であることから導けます。

問：2世帯の所得が100万円と300万円。ジニ係数を求めよ。

解答・解説：累積所得割合は0→1/4→1、世帯割合は0→1/2→1。B=(1/2)×(0+1/4)/2+(1/2)×(1/4+1)/2=1/16+5/16=3/8。G=1−2×3/8=1/4=0.25。

POINT 05

間違いやすいポイント

①軸の逆転：横軸は所得の低い順の世帯累積割合、縦軸は所得累積割合。②数値の逆転：ジニ係数は小さいほど平等に近い。③水準との混同：ジニ係数は平均所得を示しません。④統計条件の見落とし：税・社会保障による再分配前後、世帯と個人、所得と資産の違いを確認しましょう。

特に、2国のジニ係数だけを比較して「どちらの国民が豊かか」と結論づけるのは誤りです。

POINT 06

段階別演習5問と完全解説

  1. 基本：ローレンツ曲線の横軸と縦軸は何か。
    解答・解説を表示

    横軸は所得の低い順に並べた世帯（または人）の累積割合、縦軸はその人々の所得の累積割合。対象が世帯か個人かは資料の定義に従う。

  2. 基本：下位40％の世帯が所得総額の15％を受け取るとき、曲線上の点を示せ。
    解答・解説を表示

    (0.4, 0.15)。横軸は世帯の累積割合、縦軸は所得の累積割合なので逆にしない。

  3. 標準：2世帯の所得がともに100万円の場合、ジニ係数はいくつか。
    解答・解説を表示

    0。所得を低い順に並べても累積所得割合は0、0.5、1となり均等分布線に重なる。

  4. 標準：所得が0万円、100万円、200万円の3世帯のジニ係数を求めよ（折れ線で計算）。
    解答・解説を表示

    累積所得比率は0、0、1/3、1。横軸は0、1/3、2/3、1。台形の面積Bは(1/3)×(0+0)/2+(1/3)×(0+1/3)/2+(1/3)×(1/3+1)/2=5/18。G=1−2B=1−10/18=4/9。

  5. 応用：同じジニ係数の国Aと国Bなら平均所得も等しい、と言えるか。
    解答・解説を表示

    言えない。すべての所得を同じ倍率で増やしても累積所得割合は変わらず、ジニ係数も変わらない。格差の尺度だけで所得水準や生活の豊かさは決められない。

POINT 07

まとめ・関連単元・参考文献

所得の低い順に並べた累積割合がローレンツ曲線、均等分布線との面積の差を比率にしたものがジニ係数です。「曲線が下にたわむほど格差大、Gも大」と押さえ、資料の単位と定義を必ず確認しましょう。

関連単元：物価上昇と実質賃金、名目GDPと実質GDP、公共の一覧。
