関係代名詞と関係副詞

関係詞の空所補充では、先行詞だけでなく関係詞の後ろの文に「何が足りないか」を見ることが重要です。

約9分 標準 演習3問つき

EN

このページで学べること
which / who / where の選び方。要点を読んだら、最後の確認問題で理解度をチェックしましょう。

POINT 01

関係代名詞は文の要素を補う

関係代名詞は2つの文をつなぎ、関係詞節の中で主語・目的語などの働きをします。

例｜目的語が欠ける

This is the book which I bought yesterday.

I bought ___ yesterday. と目的語が足りないので which を使う。
例｜主語が欠ける

The girl who lives next door is a musician.

___ lives next door. と主語が足りないので who を使う。
POINT 02

関係副詞は「完全な文」をつなぐ

関係副詞 where / when / why の後ろには、主語や目的語がそろった文が続きます。前置詞＋関係代名詞と置き換えられる場合もあります。

先行詞典型的な関係副詞対応する表現
場所wherein / at which など
時whenon / at which など
理由whyfor which
比較｜同じ house でも…

This is the house where I lived.
This is the house which I bought.

lived には目的語が不要、bought には目的語が必要。
POINT 03

入試でのチェック手順

  1. 先行詞が人か物か、場所か時かを確認。
  2. 空所の後ろの節を読む。
  3. 主語・目的語が欠けていれば関係代名詞、そろっていれば関係副詞を検討。
注意：場所を示す先行詞でも、必ず where とは限りません。たとえば the city which I visited は visited の目的語が欠けているため which が自然です。
PRACTICE

確認問題に挑戦！

全3問。答えを考えてから「解答と解説を見る」を押してね。

Q01

This is the park (　) we played soccer.

解答と解説を見る ＋
正解・解答例

where

we played soccer は必要な要素がそろっており、場所を表す関係副詞 where を使います。

Q02

The park (　) we visited was beautiful.

解答と解説を見る ＋
正解・解答例

which / that

visited の目的語が欠けているため関係代名詞。park が場所でも where にはなりません。

Q03

The student (　) answered the question is my friend.

解答と解説を見る ＋
正解・解答例

who / that

関係詞節で主語が欠けており、先行詞が人なので who または that。

今日のまとめ

「先行詞が場所→where」と即決せず、後ろの文が完全かどうかを確認。
