二次不等式の解き方｜判別式D・重解・解なしをグラフで整理

交点2つ・重解・交点なしを、グラフと符号で判断する。

到達目標：判別式とグラフを使い、あらゆる二次不等式の解集合を説明できる。

POINT 01

学習目標と直感的な導入

二次不等式は「放物線が地面（x軸）より上か下か」を問う問題です。二次方程式が交点の位置を答えるのに対し、二次不等式は範囲を答えます。目標は①0との比較に直す、②交点を調べる、③グラフの上下で範囲を決める、④判別式Dで例外を処理する、の4つです。

f(x)=ax²+bx+c（a≠0）とおきます。f(x)>0はグラフがx軸より上、f(x)≦0はx軸上または下の点のx座標を求める意味です。

POINT 02

基本手順と符号の仕組み

まず右辺を0にしてf(x)の形へ。次にf(x)=0を解き、実数解の個数と位置を調べます。a>0なら上に開き、a<0なら下に開きます。最後に「上（正）・下（負）」と等号の有無を読みます。

特にa>0で異なる2解α<βをもつとき、f(x)=a(x−α)(x−β)。x<αでは両因子が負なので積は正、α<x<βでは符号が逆なので負、x>βでは両方正なので正です。外側が正、内側が負は暗記だけでなく積の符号から導けます。

POINT 03

判別式Dで分ける3ケース

判別式D=b²−4acで実数解の個数を判断します。D>0：交点2個、3区間の符号を判定。D=0：重解r=−b/(2a)でx軸に接し、f(x)=a(x−r)²。D<0：交点なし、f(x)は常にaと同じ符号です。

条件a>0でf(x)>0a>0でf(x)≦0
D>0x<α または x>βα≦x≦β
D=0x≠rx=rのみ
D<0すべての実数解なし

a<0なら−f(x)を考えて不等号を逆向きにする方法が確実です。

POINT 04

典型例題① 交点が2つ

問題：x²−x−6≦0を解け。

解説：(x−3)(x+2)≦0。境界は−2と3。上に開く放物線の内側で0以下となり、等号があるため両端を含みます。答え：−2≦x≦3。

POINT 05

典型例題② 係数が負

問題：−x²+4x−3>0を解け。

解説：両辺を−1倍してx²−4x+3<0（不等号が反転）。(x−1)(x−3)<0なので、上に開くグラフの内側です。答え：1<x<3。端点は等号がないため除外します。

POINT 06

典型例題③ 重解と判別式

問題：x²−6x+9>0を解け。

解説：(x−3)²>0。平方は常に0以上で、0となるのはx=3のみ。したがってx<3 または x>3。すべての実数ではありません。

なおx²+2x+5<0ならD=4−20=−16<0、a=1>0なので常に正。したがって解なしです。

POINT 07

入試で間違えやすい点

①等号：≧・≦なら根を含み、>・<なら含みません。②負の数で割る：不等号を必ず反転。③D=0：「常に正」とは限らず、接点で0です。④D<0：解なしになるのは求める符号と放物線の符号が逆の場合。⑤判別式：Dはグラフの交点数の情報であり、それだけで解の範囲は決まりません。

POINT 08

段階別演習5問・完全解説

  1. 基本：x²−7x+10>0。
    解答と途中式

    (x−2)(x−5)>0。上に開くので外側。x<2 または x>5。

  2. 基本：2x²−8x≦0。
    解答と途中式

    2x(x−4)≦0。係数2は正で、根は0と4。内側で0以下。0≦x≦4。

  3. 標準：−2x²+2x+4≧0。
    解答と途中式

    −2(x−2)(x+1)≧0。−2で割り(x−2)(x+1)≦0。−1≦x≦2。

  4. 標準：x²+4x+4≦0。
    解答と途中式

    (x+2)²≦0。平方は0以上なので0の場合のみ。x=−2。

  5. 応用：すべての実数xについてx²−2kx+4>0となる実数kの範囲を求めよ。
    解答と途中式

    a=1>0で常に厳密に正となるには、x軸との共有点がないD<0が必要十分。D=(−2k)²−16=4k²−16<0。k²<4より−2<k<2。k=±2では重解で0となり条件に反します。

POINT 09

まとめ・関連単元・参考

二次不等式は「0にそろえる→根と判別式→開く向き→上下と等号」の順に解きます。D>0だけでなく、D=0とD<0の例外も押さえましょう。
