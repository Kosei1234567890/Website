消費者余剰・生産者余剰と死荷重｜図解・計算問題で攻略

市場の「得」を三角形で可視化し、失われた利益まで計算しよう。

基礎〜応用例題3題・演習5問
目次学習目標導入：100円で買っても得は人によって違う余剰の定義とグラフ独自図解：余剰の三角形均衡と余剰の求め方典型例題3題と途中式間違えやすい点段階別練習5問・完全解説まとめ・関連単元

学習目標

支払意思額と最低受取額から消費者余剰・生産者余剰を説明し、需要供給の直線から均衡・総余剰・死荷重を計算できるようになる。

導入：100円で買っても得は人によって違う

ノートに300円まで払える人が100円で買えば、差の200円が消費者余剰。最低70円で売れる人が100円で売れば、差の30円が生産者余剰。これは架空の例で、会計上の利益と必ずしも一致しない。

余剰の定義とグラフ

消費者余剰（CS）は各単位の支払意思額−購入価格の合計。需要曲線の下、市場価格の上の面積。生産者余剰（PS）は販売価格−最低受取額の合計で、市場価格の下、供給曲線の上の面積。総余剰 TS=CS+PS。供給超過の「余剰」とは別の概念である。

需要・供給が直線なら三角形の面積＝底辺（取引量）×高さ（価格差）÷2。曲線なら単純な三角形にならないこともある。

独自図解：余剰の三角形

均衡と余剰の求め方

需要 P=100−2Q、供給 P=20+2Q。均衡は100−2Q=20+2Q → 4Q=80 → Q*=20、P*=60円。需要の価格切片は100、供給の切片は20。よってCS=20×(100−60)÷2=400円、PS=20×(60−20)÷2=400円、TS=800円。

外部性・税・取引費用などがない標準的な競争市場では、均衡数量まで追加1単位の便益が費用を上回り、均衡を超えると費用が便益を上回る。したがってこの条件下では均衡数量が総余剰を最大化する。

典型例題3題と途中式

例題1

支払意思額500円、実際の価格320円。CSは？

500−320=180円。

例題2

需要 P=90−Q、供給 P=30+Q。均衡とCS・PSは？

90−Q=30+Q → Q*=30、P*=60。CS=30×(90−60)÷2=450円、PS=30×(60−30)÷2=450円。

例題3

元の市場で取引量が20から15に制限された場合の死荷重は？

Q=15の需要価格は70、供給価格は50。差20、失われる数量5なので、死荷重DWL=5×20÷2=50円。残る取引は便益が高い順・費用が低い順に実施されると仮定する。

間違えやすい点

  • CSとPSを上下逆にしない。需要と価格の間がCS、価格と供給の間がPS。
  • 切片そのものを余剰と答えず、数量×価格差÷2を計算する。
  • 死荷重と税収は違う。税収は政府への移転、死荷重は失われた純便益。
  • 市場均衡が常に社会的最適とは限らない。外部性や情報の非対称性があれば条件が崩れる。

段階別練習5問・完全解説

基礎1

支払意思額250円、購入価格180円のCSは？

解答・解説

250−180=70円。

基礎2

最低受取額90円、販売価格140円のPSは？

解答・解説

140−90=50円。

標準3

需要P=120−Q、供給P=40+Q。均衡とTSは？

解答・解説

120−Q=40+Q → Q*=40、P*=80。CS=40×40÷2=800、PS=40×40÷2=800、TS=1600円。

標準4

元の市場で数量を10に制限する。DWLは？

解答・解説

Q=10で需要80、供給40、差40。失われる数量10。DWL=10×40÷2=200円。

応用5

元の市場で売り手に1個20円の税。買い手価格・売り手受取価格・数量・税収・DWLは？

解答・解説

買い手価格Pb=100−2Q、売り手受取価格Ps=20+2Q。Pb−Ps=20より80−4Q=20 → Q=15。Pb=70円、Ps=50円。税収=20×15=300円。DWL=(20−15)×20÷2=50円。税収は政府への移転なのでDWLと足し違えない。

まとめ・関連単元

均衡を解く → 価格線の上がCS、下がPS → 三角形の面積を足す → 取引量が減れば失われた三角形を求める。
