英語の省略・代用表現｜one・ones・do so・so do Iを文脈で解く

one/ones・do so・So do I・neither do Iを区別し、指示内容を本文に戻して訳せる。

約15分基礎〜応用例題3題・演習5問
目次学習目標導入基本解説典型例題応用ミスしやすい点演習5問まとめ

学習目標

one/ones・do so・So do I・neither do Iを区別し、指示内容を本文に戻して訳せる。

導入：繰り返しを省く英語の設計

「赤いペンはないけれど青いペンならある」を英語で言うと、I don't have a red pen, but I have a blue one. とできる。one は前の可算名詞 pen を代用する。ところが、同じ省略でも do so は動作のまとまりを代用する。入試では「何を省略したか」を復元する力が重要だ。

基本の整理：代わりに立つ語の守備範囲

表現代用するもの例
one / ones可算名詞の単数 / 複数a small one / the larger ones
do so先行する動作・行為She promised to call and did so.
so + 助動詞 + 主語肯定内容への同意So can I.（私もできる）
neither / nor + 助動詞 + 主語否定内容への同意Neither can I.（私もできない）

one は不特定の同種のものを表すことが多い。I lost my key and found it. の it は失くしたその鍵を指す。一方 I lost my key and bought a new one. の one は別の鍵だ。特定の同一物か、同種の別物かを区別しよう。

do so は先行する行為を受ける。Rina submitted the form, and Taro did so too. なら「太郎も書類を提出した」。一方、So did Taro. という倒置型は「太郎もそうした」の同意・追加を表し、語順の仕組みが異なる。be動詞の文なら So am I. のように対応する動詞を使う。

典型例題3題

例題1｜同じもの？ 別のもの？

I don't like this jacket. Show me a cheaper (　). に入る語を選べ。

解答：one。 a cheaper jacket という可算名詞単数の繰り返しを避ける。it にすると「このジャケットそのもの」を指し、a cheaper it とはできない。

例題2｜行為を受ける

They said they would apologize, and they finally (　). に do so を適切な時制で入れよ。

解答：did so。 apologize（謝罪する）という動作を受け、finally が示す完了した出来事に合わせて過去形 did を使う。

例題3｜否定への同意

A: I can't solve this puzzle. B: (　) can I. 空所に1語。

解答：Neither。 「私も解けない」。否定への同意なので Neither can I.。So can I. なら「私も解ける」で意味が逆になる。

応用：省略された内容を復元する

My sister bought two notebooks, and I bought three ones. は一般に不自然。数量詞 three の直後なら I bought three. のように ones を省くことが多い。一方 the blue ones のように形容詞で限定する複数名詞の代用は自然だ。単に「複数なら必ず ones」と暗記しない。

Ken enjoys swimming, and so does Aya. の does は enjoys swimming に対応する。so does Aya は主語 Aya より前に does が来る倒置。Aya does so なら、does so が動作を代用する別構文だ。

ミスしやすい点

① one と it の「別物／同一物」を混同しない。② 不可算名詞 water を one に機械的に置き換えない。③ So do I の do は前の文の動詞に応じて can・am・have などに変わる。④ Neither do I を「私だけは違う」と誤訳しない。⑤ 文脈上、どの名詞・動作を受けるかを必ず確認する。

段階別オリジナル演習5問

基礎1

These shoes are too tight. Do you have larger (　)?

解答・解説

ones。 shoes は複数の可算名詞で、larger ones は「もっと大きい靴（複数）」。

基礎2

I found my phone. I put (　) in my bag.（同じスマホ）

解答・解説

it。 見つけたそのスマホをカバンに入れたので、同一物を受ける it。

標準3

A: I have finished the report. B: (　) have I.（私も終えた）

解答・解説

So。 肯定への同意で、現在完了の have に対応して So have I.。

標準4

She promised to return the book, and she (　) the next day.（do so を使う）

解答・解説

did so。 return the book を動作として受け、the next day の過去の出来事なので did so。

応用5

「私はその映画を見ていないし、兄も見ていない」を neither を用いて英訳せよ。

解答・解説

I haven't seen the movie, and neither has my brother.。現在完了の否定を受け、neither + has + 主語の倒置。単に neither my brother has としない。

まとめ・次に学ぶ単元

名詞の代わりは one / ones、同一物は it、行為の代用は do so、同意の倒置は So / Neither + 助動詞 + 主語。英文を読むときは省略部分を頭の中で復元しよう。関連：並列構造、倒置構文、英語長文の読み方。
