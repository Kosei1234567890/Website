「昔は筋トレしてた」「筋トレに慣れている」「今まさに慣れているところ」。全部 used to で言おうとする客を、三兄弟が全力で止める。

タグ：面白勉強 ・ 英語

今日のゴール

① used to＋動詞原形を過去の習慣・状態として読める。② be used to＋名詞／-ing と get used to＋名詞／-ing を区別できる。③ 否定・疑問文と入試の空所補充を解ける。

時空ジム開店！ 三兄弟の自己紹介

客「昨日まで毎日腹筋してたけど、今はポテチ専門家です！」長男・昔担当「I used to exercise every day. だな。過去にはそうだったが、今は違うことを示す」。

客「今は早起きが苦じゃない！」次男・慣れ担当「I'm used to getting up early.。もう慣れてる状態だ」。

客「でも新しいジムの朝5時集合にはまだ慣れない！」三男・修行担当「I'm getting used to waking up at five.。慣れる過程の途中だ。まだ目覚まし時計と冷戦中だな」。

独自語呂：「昔は原形、慣れたらing、慣れる途中もing」。ただし後ろが名詞なら -ing は不要。「used」という見た目より、直前の be / get と後ろの形を調べよう。

三兄弟の身分証：構造と意味

used toの3用法を比較
形意味後ろ例
used to昔は〜した／〜だった動詞の原形She used to swim.
be used to〜に慣れている名詞・動名詞She is used to swimming.
get used to〜に慣れる名詞・動名詞She got used to swimming.

理由：過去の習慣の used to に続く to は不定詞の一部なので原形。一方 be/get used to の to は前置詞なので、動詞を続けるなら動名詞 -ing が必要。get は変化、be は状態を表す。

否定は didn't use to＋原形、疑問は Did you use to＋原形? が標準的。did が過去を担うため use に戻る。be/get used to の否定・疑問は通常の be 動詞や get の規則に従う（例：Are you used to the noise?）。

例題3題：ジム入会試験

例題1｜I (　) play tennis, but I don't now.

答え：used to。but I don't now が過去と現在の対比を示す。play は原形で、昔の習慣を表す。

例題2｜He is used to (　) in front of people. [speak]

答え：speaking。is used to は「慣れている」。to が前置詞だから speak を動名詞にする。

例題3｜It took me a month to get used to (　) on the left. [drive]

答え：driving。get used to は「慣れるようになる」。運転に慣れるまで1か月かかったという意味。to の後は -ing。

落とし穴：to の制服が同じでも所属部署は違う

× I am used to wake up early. → ○ I am used to waking up early.。be used to の後は動名詞。× Did you used to live here? → 標準的には ○ Did you use to live here?。なお used to は過去の習慣だけでなく He used to be shy. のような過去の状態にも使える。would は反復動作には使えるが、過去の状態を同じようには表せない。

段階別演習5問：時空ジム卒業試験

基礎1

「私は昔ここに住んでいた」を I (　) live here. で完成させよ。

解答・解説を開く

used to。過去の状態が現在と異なることを示す。後ろの live は原形。

基礎2

She is used to (work / working) at night. 正しい形を選べ。

解答・解説を開く

working。is used to は慣れている状態で、to は前置詞。したがって動名詞。

標準3

「あなたは昔、徒歩で通学していましたか」を英訳せよ。

解答・解説を開く

Did you use to walk to school?。did によって過去の疑問文を作り、use は原形。walk to school は徒歩で通学する。

標準4

When I moved to the city, I couldn't sleep, but I gradually (　) used to the noise. 空所に get の適切な形を入れよ。

解答・解説を開く

got。引っ越した過去から次第に慣れた変化を表すので got used to。noise は名詞だから -ing にする必要はない。

応用5

次の2文の意味の違いを説明せよ。A: I used to study at night. B: I'm used to studying at night.

解答・解説を開く

Aは「以前は夜に勉強していた（今はそうではない）」という過去と現在の対比。Bは「夜に勉強することに慣れている」という現在の状態。Aの to は不定詞、Bの to は前置詞なので study と studying が分かれる。

まとめ：三兄弟の顔より名札を見ろ

昔の習慣・状態は used to＋原形。慣れた状態は be used to＋名詞／-ing。慣れる変化は get used to＋名詞／-ing。did が来たら used ではなく use に戻す。迷ったら「過去／状態／変化」のどれかを先に判定しよう。
