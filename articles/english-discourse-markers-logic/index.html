英語長文の接続表現｜however・therefore・moreoverを論理で読み解く

接続語を丸暗記するだけでなく、前後の意味から判断する。

基礎〜入試応用例題3題・演習5問
この記事の目次学習目標導入：単語が読めても論理が逆転する5つの関係を地図にする文法上の落とし穴典型例題3題よくあるミス段階別演習5問と完全解説まとめ・関連単元

学習目標

①接続表現を暗記でなく前後の論理関係から判断する。②逆接・因果・追加・例示・譲歩を区別する。③長文の空所補充と段落要旨に応用する。

導入：単語が読めても論理が逆転する

「学校の図書館は静かだ。＿＿、試験前には席が足りない。」この空所は however が自然だ。静かな環境という長所に対して、混雑という問題を提示しているからである。接続語を選ぶ前に、2文を短い日本語で要約することが出発点になる。

5つの関係を地図にする

接続表現と前後の意味関係
関係代表表現読み方
逆接・対比however, nevertheless, in contrastAだがB
因果・結果therefore, consequently, as a resultAだからB
追加moreover, furthermore, in additionAに加えB
例示for example, for instanceAの具体例B
類似similarly, likewiseAと同様にB

時間順序を示す meanwhile, subsequently なども重要だが、論理関係と時間関係を混同しない。therefore は結果を述べ、because は理由を導く。両者は単純に置き換えられない。

読み取り図：主張A →（理由・結果・反対・具体例のどれか）→ 主張B。まず矢印の意味を言語化し、その後に語を選ぶ。

文法上の落とし穴

Although the task was difficult, we finished it. は although が従属接続詞で節を導く。一方 The task was difficult. However, we finished it. は however が文全体のつながりを示す副詞的表現である。Although the task was difficult. However, ... と切ると、最初の although 節が独立した文にならず不自然だ。

Despite the rain, the event continued. の despite は前置詞なので後ろに名詞句を置く。Although it rained, ... の although は節を導く。接続表現は意味だけでなく後続する形も確認する。

典型例題3題

例題1：逆接

Many students prefer digital notes. (　), some still find paper easier to review. 選択肢：Therefore / However / For example

解答：However。「デジタルを好む学生が多い」対「紙を見直しやすいと感じる学生もいる」という対比。Therefore は因果、For example は具体例を表すため不適切。

例題2：結果

The bridge was closed for repairs. (　), drivers had to take another route. 選択肢：As a result / Similarly / Nevertheless

解答：As a result。橋が閉鎖されたことが原因、別ルートを使う必要が生じたことが結果である。

例題3：語法

空所を埋めよ： (　) the heavy traffic, we arrived on time. 選択肢：Although / Despite / Therefore

解答：Despite。後ろは名詞句 the heavy traffic。Although を使うなら Although the traffic was heavy, ... のように主語と動詞を含む節が必要。

よくあるミス

「逆の内容があるから always however」と決めつけない。譲歩は「AにもかかわらずB」、対比は「Aに対してB」と、関係が微妙に異なる。on the other hand は二つの観点の対置で使われることが多い。for example は前の一般論を具体化するので、具体例を先に見つける。

段階別演習5問と完全解説

基礎1

She practiced every day. (　), her performance improved. [Therefore / However]

解答・解説

Therefore。毎日練習した結果、演奏が上達した。原因→結果なので therefore。

基礎2

Some birds migrate long distances. (　), swallows travel between regions as seasons change. [For example / Nevertheless]

解答・解説

For example。渡り鳥という一般論をツバメという具体例で示している。

標準3

(　) she was tired, she completed the report. [Although / Despite]

解答・解説

Although。後ろは she was tired という節。Despite は名詞句または動名詞句を伴うのでそのままでは不可。

標準4

The first experiment used warm water. (　), the second used cold water. [In contrast / Consequently]

解答・解説

In contrast。二つの実験条件を比較している。前の実験が後の実験を引き起こしたわけではない。

応用5：段落の要旨

Online courses allow learners to study at their own pace. Moreover, recorded lessons can be replayed. However, learners may miss face-to-face discussion. 筆者が挙げる利点2つと課題1つを日本語で答えよ。

解答・解説

利点：自分のペースで学べること、録画授業を繰り返し見られること。課題：対面での議論の機会が不足し得ること。Moreover は利点の追加、However は利点から課題への転換を示す。単に最後の文だけを要旨とせず、段落全体の構成を押さえる。

まとめ・関連単元

接続表現は「語を覚える→当てはめる」より「前後を要約→関係を決める→文法の形を確認」の順で読む。特に however＝対比、therefore＝結果、moreover＝追加、for example＝具体化 を軸に、文章全体の流れを追おう。
