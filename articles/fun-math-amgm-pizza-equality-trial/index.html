ピザの分配裁判で相加相乗平均の証明と等号条件を身につける。

本日の判決目標

正の数の相加平均・相乗平均の関係を証明し、最小値の問題で使う。さらに「下界が出た」だけでは最小値と断定できない理由を、等号条件で判定できるようになる。

第1幕：ピザ分配裁判、開廷

裁判長「2人にピザを4枚と9枚配った。足して割る平均は6.5枚だ！」弁護人「掛けて平方根を取る平均は6枚です！」検察官「なぜ小さい？」裁判長「偏った配分ほど、掛け算側が不利になるのだ」。ここでの4と9はピザの枚数を表す正の数。平均はそれぞれ (4+9)/2=6.5、√(4×9)=6。両者が同じ枚数なら一致する。

独自語呂：「足して半分、掛けてルート。同じになれば等号ルート！」

ただし、語呂は覚える入口。答案では必ず正の条件と等号成立を確認しよう。

第2幕：証拠品は二乗の非負性

a,b≥0 なら (√a−√b)²≥0。展開して a+b−2√(ab)≥0、したがって (a+b)/2≥√(ab)。等号は √a=√b、つまり a=b の場合に限る。入試で頻出の形は a+b≥2√(ab)。

ピザ分配の証拠記録
a,b相加平均相乗平均等号
4,96.56不成立
5,555成立
1,168.54不成立

図解の読み方：等号が成立するのは配分が一致したときだけ。平方差はそのずれを測る非負の証拠になる。

例題3題：判決は等号まで書いて完成

例題1：x>0 のとき x+9/x の最小値

x と 9/x は正で積が9。ゆえに x+9/x≥2√9=6。等号は x=9/x、すなわち x²=9。x>0 より x=3 が実在するので、最小値6（x=3）。

例題2：x>0 のとき 2x+8/x の最小値

2x と 8/x の積は16。よって 2x+8/x≥8。等号は 2x=8/x、x²=4。x=2 で成立。最小値8。

例題3：x>0 のとき (x+1)(1+4/x) の最小値

展開すると x+5+4/x。x+4/x≥4（x=2で等号）。したがって全体は≥9。最小値9（x=2）。積をそのまま公式に当てるより、展開して「積一定の2項」を探すのが近道。

よくある誤答：判決取り消し3連発

①負の数に適用：a=−1,b=−4 では√(ab)を使った同じ議論はできない。公式の前提は a,b≥0。②等号条件の未確認：x+1/x≥2 は x>0 で正しいが、x≥2 という条件を追加すると x=1 は使えず、最小値は x=2 の 5/2。③和が一定なのに和の最小値を探す：公式が役立つのは、和一定なら積の最大、積一定なら和の最小という向き。条件を見てから使う。

段階別5問：ピザ裁判の司法試験

基礎1：a=1,b=9 の相加平均と相乗平均を求めよ。
解答と根拠

(1+9)/2=5、√(1×9)=3。5≥3で等号不成立。

基礎2：x>0 のとき x+16/x の最小値。
解答と根拠

積が16なので和≥8。x=16/x より x=4 で等号。最小値8。

標準3：x>0 のとき 3x+12/x の最小値。
解答と根拠

積は36、和≥12。3x=12/x より x=2 で等号。最小値12。

標準4：x>0 のとき x+1/x≥2 を証明し等号条件を示せ。
解答と根拠

x,1/x は正で積1。相加相乗平均から和≥2√1=2。等号は x=1/x、x>0 より x=1。

応用5：x≥2 のとき x+1/x の最小値を求めよ。公式だけで2と答えてよいか。
解答と根拠

公式による下界2の等号は x=1 で、定義域外。x≥2 で x+1/x−5/2=(2x−1)(x−2)/(2x)≥0。よって x=2 で最小値5/2。下界と最小値を混同しない。

閉廷：公式より等号が大事

相加平均≥相乗平均は二乗の非負性から導ける。適用前に2項が非負か確認し、最小値・最大値を答えるときは等号を満たす値が定義域にあるか調べよう。
