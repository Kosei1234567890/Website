階差数列の一般項｜差を足して元の数列を復元する方法

到達目標：階差数列の定義・復元公式を証明し、典型的な数列の一般項を求められる。

POINT 01

学習目標と導入

目標は①隣り合う項の差を階差数列として表す、②差を足して元の数列の一般項を求める、③最初の項だけ別扱いになる理由を説明することです。

例えば数列 2, 5, 10, 17, 26, … は、一見不規則でも差を取ると 3, 5, 7, 9, … です。差の規則を発見すれば元の数列を復元できます。

POINT 02

階差数列の定義と復元公式

数列 {an} の階差数列を bn = an+1 − an と定めます。つまり an+1 = an + bn です。

n ≧ 2 について、an = a1 + (a2−a1) + … + (an−an−1)。途中の項が消えるため、次の公式を得ます。

an = a1 + Σk=1n−1 bk （n ≧ 2）

n=1では和の項数が0となるため、空和を0と約束すれば同じ式が使えます。ただし学校の解答では n ≧ 2 で導出し、最後に n=1 も確認する書き方が安全です。

POINT 03

典型例題① 等差の階差

問題：a1=2、bn=2n+1 のとき an を求めよ。

解説：n ≧ 2 で an=2+Σ(2k+1)（k=1からn−1）。Σ2k=n(n−1)、Σ1=n−1 なので an=2+n(n−1)+(n−1)=n²+1。n=1でも2となり一致します。

POINT 04

典型例題② 等比の階差

問題：a1=4、bn=3·2n−1 のとき an を求めよ。

解説：階差の和は 3(1+2+…+2n−2)=3(2n−1−1)。よって an=4+3(2n−1−1)=3·2n−1+1。n=1も4で一致します。

POINT 05

典型例題③ 元の数列から階差を見抜く

問題：1, 4, 9, 16, 25, … の一般項を階差から求めよ。

解説：階差は3,5,7,9,… で bn=2n+1。a1=1 だから an=1+Σ(2k+1)=1+n(n−1)+(n−1)=n²。単に平方数と気づくだけでなく階差によって証明できます。

POINT 06

入試での落とし穴

①上端はnではなくn−1：第1項から第n項へ移動する回数はn−1回です。②階差の初項：b1=a2−a1。③初項の検算：n ≧ 2 の式を求めたらn=1を代入し、初項と一致するか確かめます。④見た目の数列：有限個の項だけでは一般項は一意に決まりません。問題文の規則や階差の条件が与えられているか確認しましょう。

段階別練習問題5問・完全解説

問1（基礎）

a₁=3、bₙ=4（n≧1）。aₙを求めよ。

解答と途中式を見る

aₙ=3+4(n−1)=4n−1。n=1で3。

問2（基礎）

a₁=5、bₙ=n。a₅を求めよ。

解答と途中式を見る

a₅=5+(1+2+3+4)=15。a₅までの差は4個。

問3（標準）

a₁=1、bₙ=3n²+3n+1。aₙを求めよ。

解答と途中式を見る

bₙ=(n+1)³−n³。したがって aₙ=1+Σ[(k+1)³−k³]=1+(n³−1)=n³。

問4（標準）

a₁=2、bₙ=2·3ⁿ。aₙを求めよ。

解答と途中式を見る

Σ（k=1からn−1）2·3ᵏ = 2·3(3ⁿ⁻¹−1)/(3−1)=3ⁿ−3。よって aₙ=3ⁿ−1。n=1で2。

問5（応用）

a₁=2、bₙ=2n+1。aₙが101となる自然数nを求めよ。

解答と途中式を見る

aₙ=n²+1。n²+1=101よりn²=100。自然数だからn=10。

まとめと次の学習

階差を bₙ=aₙ₊₁−aₙ と定義し、初項に n−1 個の階差を加える。公式の上端と初項の検算が得点の鍵です。
