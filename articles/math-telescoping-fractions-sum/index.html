到達目標：部分分数分解を証明し、有限和の消去と端点を説明できる。

POINT 01

学習目標と直感

1項ずつ足すと大変な分数の和も、隣同士で打ち消し合う形に変形すれば、端の項だけが残ります。この記事では①部分分数分解の根拠、②Σの端点管理、③一般化と検算を習得します。

例えば 1/2+1/6+1/12+1/20 は、分母が k(k+1) の形です。小数にせず構造を探しましょう。

POINT 02

なぜ分解できるのか

kが正の整数なら 1/[k(k+1)] = 1/k − 1/(k+1)。右辺を通分すると [(k+1)−k]/[k(k+1)] = 1/[k(k+1)] となり、恒等式が証明されます。

Σk=1n 1/[k(k+1)] = (1−1/2)+(1/2−1/3)+…+(1/n−1/(n+1)) = 1−1/(n+1) = n/(n+1)

途中の 1/2, 1/3, …, 1/n は正負1回ずつ現れて相殺。残るのは最初の正の項と最後の負の項です。

POINT 03

典型例題① 基本の和

問題：Σ(k=1〜9) 1/[k(k+1)] を求めよ。

解説：1/k−1/(k+1) として展開すると、1−1/10 = 9/10。n=9を公式 n/(n+1) に代入しても一致します。最終項は k=9 なので負の端は −1/10 です。

POINT 04

典型例題② 係数がある分母

問題：Σ(k=1〜6) 1/[(2k−1)(2k+1)] を求めよ。

解説：1/[(2k−1)(2k+1)] = (1/2){1/(2k−1)−1/(2k+1)}。和は (1/2)(1−1/13)=6/13。分母の差が2なので係数1/2を忘れません。

POINT 05

典型例題③ 始点が1でない

問題：Σ(k=4〜12) 1/[k(k+1)] を求めよ。

解説：展開すると (1/4−1/5)+…+(1/12−1/13)=1/4−1/13=(13−4)/52=9/52。始点4のとき最初に残るのは1/4であり、1ではありません。

POINT 06

一般化と落とし穴

a,bが異なる実数で k+a と k+b が0でなければ、1/[(k+a)(k+b)] = {1/(k+a)−1/(k+b)}/(b−a)。ただし隣接項が消えるのは、例えば b=a+1 のように添字がうまくつながる場合です。単に部分分数分解しただけで必ず望遠鏡型になるわけではありません。

注意：①通分の符号を逆にしない、②始点と終点を必ず書く、③分母が0になる値は除外、④無限和に進む場合は部分和の極限を確認します。

段階別練習問題5問・完全解説

問1（基礎）

Σ(k=1〜4) 1/[k(k+1)]

解答と途中式を見る

1−1/5=4/5。項は1/2+1/6+1/12+1/20であり、通分しても4/5。

問2（基礎）

Σ(k=3〜7) 1/[k(k+1)]

解答と途中式を見る

1/3−1/8=(8−3)/24=5/24。始点を1に戻さない。

問3（標準）

Σ(k=1〜5) 2/[(k+1)(k+2)]

解答と途中式を見る

2{1/(k+1)−1/(k+2)}を用いる。2(1/2−1/7)=5/7。

問4（標準）

Σ(k=1〜n) 1/[(3k−2)(3k+1)]

解答と途中式を見る

各項は(1/3){1/(3k−2)−1/(3k+1)}。よって(1/3){1−1/(3n+1)}=n/(3n+1)。n=1で1/4となり元の項と一致。

問5（応用）

Σ(k=1〜n) 1/[k(k+1)] が 19/20 となる自然数 n を求めよ

解答と途中式を見る

n/(n+1)=19/20。20n=19n+19よりn=19。分母は20で正、条件を満たす。

まとめと次の学習

分母を差に分解→和を展開→中間項を消去→端の項を計算。途中で添字の範囲を書けばミスが減ります。
