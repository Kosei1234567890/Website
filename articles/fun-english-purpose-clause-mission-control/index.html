目的のtoとso thatは宇宙船の管制室!?｜主語交代と否定の罠を攻略

目的語じゃない、目的の話。宇宙船の操縦士と管制官が英文法を救う！

約15分基礎〜入試応用例題3題・演習5問
目次学習目標宇宙船の寸劇3つの文型と根拠典型例題3題誤答の罠段階別演習5問まとめ

学習目標

①目的の不定詞とso that節の形を区別する。②目的を実行する人が変わる場合に適切な文を作る。③否定の位置と「結果」のso ... thatを見抜く。

第1幕：宇宙船の管制室で文法事故

船長「I pressed the button to open the door. 私が押して、私が開ける！」管制官「じゃあ僕が脱出するために押して！」船長「I pressed the button to you escape!」英文法AI「警告！toの直後にyouを密航させるな！」管制官「I pressed the button so that you could escape. なら僕が逃げられる！」

オリジナル語呂：同じ操縦士ならtoでGO、乗員交代ならso that号！

これは基本的な使い分けの目安。so thatは同じ主語でも使えるので「主語が同じならso that禁止」ではない。

管制マニュアル：目的の3ルート

目的表現の形と主語
形後ろ例
to / in order to動詞の原形We trained to win.
so that主語＋動詞We trained so that we could win.
in order not to動詞の原形We slowed down in order not to crash.

理由：目的のto不定詞は主語を明示しない非定形表現で、通常は主節の主語が目的行為の担い手になる。一方so thatは主語と定形動詞を含む節なので別の人を主語にできる。助動詞can/could/will/wouldを伴うことが多いが必須ではない。

結果との違い：We were so tired that we stopped. は「とても疲れたので止まった」という程度・結果。so + 形容詞/副詞 + that を見つけたら目的のso thatと混同しない。なおso that自体にも文脈によって結果用法がある。

典型例題3題：管制官の資格試験

例題1：I saved money ( ) buy a telescope.

答え：to。buyは動詞原形で、貯金する人と買う人が同じ。in order toも可能だが空欄が1語なのでto。

例題2：I lowered the ladder ( ) the astronaut could climb aboard.

答え：so that。the astronautという明示的主語とcould climbが続く。to the astronaut could ... は不可。

例題3：We spoke quietly ( ) wake the sleeping pilot.

答え：in order not to（またはso as not to）。起こさないことが目的。否定語notはtoの直前に置く。

事故報告：やらかしポイント

「for buy」は不可。forの後には名詞句を置けるが、動詞原形の目的ならto buy。「so that to escape」も不可で、so thatの後ろには主語＋動詞を置く。「so tired that」は目的でなく程度・結果。また、目的が実現したとは限らない。I ran to catch the bus. だけでは実際に乗れたかは不明だ。

段階別演習5問：宇宙船の最終点検

基礎1

She opened a notebook (to / so that) record the result. 選びなさい。

解答・完全解説

to。recordは動詞原形で、主語sheが記録する。so thatならshe could recordなど主語＋動詞が必要。

基礎2

We turned on the light ( ) everyone could read the map. 2語で補いなさい。

解答・完全解説

so that。everyone could readが節であり、点灯したweと読むeveryoneは別の主語。

標準3

He checked the fuel twice in order (not / to / forget) the safety rule. 語を並べ替えなさい。

解答・完全解説

not to forget。完成文はin order not to forget ...。目的を否定するときnotはtoの前。

標準4

「私は妹が試験に間に合うようにタクシーを呼んだ」をso thatで英訳しなさい。

解答・完全解説

I called a taxi so that my sister could get to the exam on time. など。呼ぶ人はI、間に合う人はmy sister。過去の目的なのでcouldを用いるのが自然。

応用5

次の2文を「目的」「程度・結果」に分類し、根拠を述べよ。A: I moved aside so that she could see the board. B: The screen was so bright that I closed my eyes.

解答・完全解説

Aは目的、Bは程度・結果。Aはso that以下が「彼女が見られるように」という意図を表す。Bはso bright thatというso＋形容詞＋thatの構造で、画面が非常に明るかった結果、目を閉じたことを表す。

まとめ：主語が交代したら管制室を呼べ

目的のto / in order toの後ろは動詞原形。so thatの後ろは主語＋動詞。否定の目的はin order not to。so＋形容詞＋thatは程度・結果。構文を暗記するだけでなく「誰が何をする目的か」を確かめよう。
